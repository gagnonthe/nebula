# 📄 Guide du Bouton PDF Nebula

## Partager vos PDF en un clic depuis le visualiseur Chrome !

### 🎯 Où trouver le bouton ?

Lorsque vous ouvrez un PDF dans Chrome, vous verrez un nouveau bouton **rose "Nebula"** dans la barre d'outils en haut à droite, à côté des boutons :
- 🖨️ Imprimer
- ⬇️ Télécharger
- 🔍 Zoom

---

### 🚀 Comment l'utiliser ?

#### Étape 1 : Ouvrir un PDF
- Ouvrez n'importe quel PDF dans Chrome :
  - PDF local (fichier de votre ordinateur)
  - PDF en ligne (depuis un site web)
  - PDF téléchargé

#### Étape 2 : Cliquer sur "Nebula"
- Cliquez sur le bouton **rose "Nebula"**
- Le bouton change de couleur et affiche "Upload..."
- Le PDF est téléchargé et uploadé automatiquement

#### Étape 3 : Confirmation
- ✅ **Succès** : Le bouton devient vert avec "Envoyé !"
- Une notification système s'affiche
- Le PDF est disponible sur tous vos appareils Nebula
- Le bouton revient à la normale après 3 secondes

---

### 📱 États du bouton

| État | Couleur | Icône | Texte | Signification |
|------|---------|-------|-------|---------------|
| 🟣 Normal | Rose (#FF1493) | ⬆️ | Nebula | Prêt à uploader |
| 🔵 Upload | Rose (opaque) | ⭕ | Upload... | Téléchargement et upload en cours |
| 🟢 Succès | Vert (#10b981) | ✅ | Envoyé ! | PDF partagé avec succès |
| 🔴 Erreur | Rouge (#ef4444) | ❌ | Erreur | Échec (voir message d'alerte) |

### ⚙️ Configuration requise

Pour que le bouton fonctionne, assurez-vous que :
1. ✅ L'extension Nebula est **installée et activée**
2. ✅ Vous avez **configuré l'URL du serveur**
3. ✅ Vous êtes **connecté** à Nebula (avec un deviceId)

Si le bouton ne fonctionne pas, ouvrez le popup de l'extension et vérifiez votre configuration.

---

### 🔧 Dépannage

#### Le bouton n'apparaît pas
- **Solution 1** : Rechargez la page PDF (F5)
- **Solution 2** : Vérifiez que l'extension est activée
- **Solution 3** : Réinstallez l'extension si nécessaire

#### "Configuration requise"
- Ouvrez le popup de l'extension
- Entrez l'URL du serveur Nebula
- Cliquez sur "Sauvegarder"
- Rechargez la page PDF

#### Erreur d'upload
- Vérifiez votre connexion internet
- Assurez-vous que le serveur Nebula est accessible
- Vérifiez que le PDF n'est pas trop volumineux (limite : 1 Go)

#### Le PDF ne s'affiche pas sur les autres appareils
- Attendez quelques secondes (synchronisation)
- Actualisez la liste des fichiers sur l'autre appareil
- Vérifiez que les appareils sont bien connectés

---

### 💡 Astuces

1. **Raccourci clavier** : Utilisez `Ctrl/Cmd + P` pour imprimer, mais le bouton Nebula est juste à côté !

2. **PDFs volumineux** : Les PDF de plusieurs Mo peuvent prendre quelques secondes à uploader

3. **Nom du fichier** : Le nom original du PDF est préservé lors de l'upload

4. **Accès privé** : Les PDF uploadés suivent les règles de confidentialité de Nebula

5. **Multi-appareils** : Parfait pour passer d'un écran à l'autre pendant la lecture
