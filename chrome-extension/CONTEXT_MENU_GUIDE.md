# 🖱️ Guide du Menu Contextuel Nebula

## Partager du contenu en un clic droit !

### 📸 Partager une image

1. **Naviguez** sur n'importe quel site web
2. **Clic droit** (ou deux doigts sur Mac) sur une image
3. **Sélectionnez** "🚀 Partager sur Nebula"
4. ✅ L'image est téléchargée et uploadée automatiquement !

**Exemples d'utilisation :**
- Partager des photos depuis les réseaux sociaux
- Sauvegarder des images de produits
- Transférer des infographies entre appareils
- Partager des mèmes rapidement 😄

---

### 🔗 Partager un lien

1. **Clic droit** sur n'importe quel lien hypertexte
2. **Sélectionnez** "🚀 Partager le lien sur Nebula"
3. ✅ Le lien est enregistré et accessible partout !

**Exemples d'utilisation :**
- Sauvegarder des articles à lire plus tard
- Partager des vidéos YouTube entre PC et mobile
- Collecter des ressources pour un projet
- Synchroniser vos bookmarks

---

### 📝 Partager du texte

1. **Sélectionnez** n'importe quel texte sur une page web
2. **Clic droit** sur la sélection
3. **Choisissez** "🚀 Partager le texte sur Nebula"
4. ✅ Le texte est disponible sur tous vos appareils !

**Exemples d'utilisation :**
- Copier des citations importantes
- Sauvegarder des extraits d'articles
- Transférer des adresses ou numéros de téléphone
- Partager des recettes depuis un site

---

## 🔔 Notifications

Vous recevrez des notifications pour :
- ⏳ **Téléchargement en cours** : "📥 Téléchargement de l'image..."
- ✅ **Succès** : "✅ Image partagée: nom_fichier.jpg"
- ⚠️ **Configuration requise** : Si l'extension n'est pas configurée
- ❌ **Erreurs** : En cas de problème de connexion

---

## ⚙️ Configuration requise

Pour utiliser le menu contextuel, assurez-vous que :
1. ✅ L'extension est **configurée** avec l'URL du serveur
2. ✅ Vous êtes **connecté** à Nebula
3. ✅ Vous avez un **deviceId** enregistré

Si vous voyez "⚠️ Configuration requise", ouvrez l'extension et configurez-la d'abord !

- **Rapide** : Partage en 2 clics
- **Universel** : Fonctionne sur tous les sites web
- **Automatique** : Pas besoin de télécharger puis uploader
- **Synchronisé** : Disponible instantanément sur tous vos appareils
- **Intelligent** : Détecte automatiquement le type de contenu

---

## 💡 Astuces

- Le menu s'adapte au contexte : seules les options pertinentes s'affichent
- Les images sont téléchargées avec leur nom d'origine
- Les liens et textes sont horodatés automatiquement
- Vous pouvez partager depuis n'importe quel onglet Chrome

---

## 🛠️ Dépannage

### Le menu n'apparaît pas
- Vérifiez que l'extension est bien activée
- Rechargez la page web
- Vérifiez les permissions de l'extension

### "Erreur lors du partage"
- Vérifiez votre connexion internet
- Assurez-vous que le serveur Nebula est accessible
- Ouvrez l'extension et vérifiez la configuration

### "Configuration requise"
- Ouvrez le popup de l'extension
- Entrez l'URL du serveur Nebula
- Cliquez sur "Sauvegarder"
